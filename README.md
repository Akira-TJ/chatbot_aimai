1. アプリの概要と開発目的

アプリの概要
本アプリは、仕事の依頼文に含まれる曖昧な表現や不足している情報を、生成AIを活用して分析するWebアプリケーションです。
ユーザーが依頼文を入力すると、Google Gemini APIが文章を分析し、不足している項目やその理由、追加で確認すべき質問を提示します。さらに、分析結果をもとに、より具体的で分かりやすい依頼文を生成します。

開発目的
日常生活では、「なるべく早く対応してください」「いい感じにまとめてください」といった曖昧な指示によって、依頼者と作業者の間で認識のずれが生じることがあります。
本アプリは、こうした問題を減らすために、依頼文に不足している情報を可視化し、具体的な文章への改善を支援することを目的としています。

主な機能
依頼文の分析：入力された文章の曖昧な表現や情報不足をAIが分析します。
不足項目の表示：期限、担当者、目的、成果物、完成条件、対象範囲、形式・分量、優先順位の8つの観点から確認します。
問題点と理由の提示：何が曖昧なのか、なぜ明確にする必要があるのかを表示します。
改善後の文章の生成：分析結果をもとに、より具体的で分かりやすい依頼文を生成します。
追加確認事項の提示：依頼者に確認すべき質問を表示します。
チャット形式での操作：入力文と分析結果を会話形式で確認できます。
入力例の表示：サイドバーのサンプル文章を選択し、手軽に機能を試せます。
会話履歴の管理：過去の入力と分析結果を表示し、履歴をクリアできます。

依頼文を入力すると、分析結果、不足項目、追加確認事項、改善後の文章が表示されます。
元の依頼文と改善後の文章を左右に並べることで、どのように文章が改善されたのかを比較できる構成にしました。

工夫した点
単に文章を言い換えるだけではなく、期限、担当者、目的、成果物など、業務の依頼に必要な情報を8つの観点から分析するようにしました。
表現の分かりやすさだけでなく、業務を進めるうえで確認すべき情報も把握できるようにしました。

AIが改善後の文章を作成する際、入力されていない事実を推測して確定しないように指示を設定しました。
例えば、期限が不明な場合は具体的な日付を勝手に設定せず、「［要確認：期限］」と表示します。
AIの回答をそのまま利用するのではなく、人が確認して完成させることを前提とした設計にしています。

不足項目を展開式の表示にし、元の文章と改善後の文章を左右に配置しました。
これにより、分析結果を整理して確認でき、改善前後の違いも比較しやすくしました。

オリジナリティ・独自性
本アプリでは、一般的な生成AIチャットとは異なり、業務の依頼文に特化した分析と改善を行うことを重視しました。

特に、次の点を独自の工夫として取り入れています。
業務上の依頼に必要な情報を8つの観点に整理したこと。
不足項目だけでなく、その理由と追加確認の質問も提示すること。
不明な情報をAIが勝手に確定せず、確認用のプレースホルダーを利用すること。
分析結果と改善後の文章を一画面で確認できるようにしたこと。
入力例を用意し、初めて利用する人でも操作を試せるようにしたこと。
また、AIを活用して実装方法やプロンプトの設計を検討し、アプリの目的に合わせて機能と画面構成を組み立てました。
